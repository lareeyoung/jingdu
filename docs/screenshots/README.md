# 截图与演示素材

本目录为镜读 1.5.3 的真实应用界面截图。截图使用独立的临时演示项目，复用发布版的界面和播放、时间轴、阅读、笔记与混剪功能；没有修改界面外观，也没有使用生成式图片仿制界面。没有载入个人作品库或模型账号。

- `overview.jpg`：画面优先、相邻镜头对照与镜头笔记。
- `script.jpg`：完整脚本和视频左右对照。
- `subtitles.jpg`：原文／中文双行字幕、当前句高亮与字幕轨。
- `remix.jpg`：从两个研究项目收集片段，加入原片声音进行混剪练习。

脚本、中文译文和学习笔记是人工整理的示例内容，不代表 Seed 的模型生成效果。英语原文使用本地 Whisper small 对预告片的转写；时间和译文仍需人工校对。主项目与动作研究项目使用同一预告片的不同范围，以展示跨项目收集功能。混剪中的音频取自原片音轨，并非生成音乐。
